# Workspace Rule: .NET & C# Guidelines

- **Primary Stack**: Strictly **C#** and **.NET** (ASP.NET Core MVC).
- **Course Concepts**: C#, ASP.NET MVC, ADO.NET (`DbConnection`, `DbCommand`, `DbDataReader`), and ASP.NET Core.
- **Allowed Libraries**: Any supporting libraries / NuGet packages can be used as needed.
- **Build Quality**: Must compile and run with 0 errors via `dotnet run` and Visual Studio.
